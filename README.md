مشروع تنفيذ الـ Circular Buffer
واجب مادة لغةسي - CE-ESY26
هذا الكود هو تطبيق عملي لمفهوم "المخزن الدائري" بلغة C. الفكرة الأساسية هي بناء هيكل بيانات يستفيد من المصفوفة بشكل دائري بحيث يتم ربط نهايتها ببدايتها لتوفير استهلاك الذاكرة وتسهيل التعامل مع البيانات المتدفقة.
الأجزاء الرئيسية في الكود:
هيكل البيانات (Struct): يتضمن المصفوفة الأساسية ومؤشرات الرأس (Head) والذيل (Tail) مع عداد لمتابعة حجم البيانات.
دالة التهيئة: لتصفير العدادات عند بدء التشغيل.
دالتا الإدخال والقراءة: تتعاملان مع منطق "باقي القسمة" (%) لضمان الدوران داخل المصفوفة، مع رسائل تنبيهية في حال الامتلاء (Overflow) أو الفراغ (Underflow).
تجربة البرنامج:
قمت باختبار البرنامج عن طريق إدخال اسمي وإضافة اللاحقة المطلوبة "CE-ESY"، وتم تخزين المحارف واسترجاعها بنجاح مع تجربة أحجام مختلفة للمخزن للتأكد من فاعلية التنبيه عند امتلاء الذاكرة.
